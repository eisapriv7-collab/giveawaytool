CHETOPOLY

A 3D giveaway board — 40 tiles, dice, and prizes you can edit live.

WEBGL · THREE.JS · NO INSTALL
VERSION 1
MODE · CLASSIC

Race to the Finish

Unlimited rolls. First player to complete the lap and cross GO wins it all.

  • Unlimited rolls per player
  • 40-second turn clock
  • Best for fast, high-energy giveaways
▶ PLAY VERSION 1 VERSION 2
MODE · PRIZE REVEAL

Rolls-to-Prize

Each player gets a limited number of rolls — wherever they land becomes their prize.

  • 2, 3 or 5 rolls per player
  • Doubles roll again
  • Everyone lands a prize — no losers
▶ PLAY VERSION 2
How to run it: paste player names (comma separated) into the box in-game, then hit Start. Click any tile on the board to rename it, recolour it, set a custom prize message, or drop in your own image. Type !roll in the in-game chat box to roll the dice.
